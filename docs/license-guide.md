# 방송 라이선스 안내

> ⚠️ 초안 — 가격·구매처 링크는 상품 페이지 확정 후 기입.

## 무엇인가요

- 게임의 **모든 기능은 무료**로 플레이할 수 있습니다.
- 방송(공개 송출)에 사용하실 경우, 게임 화면에 표시되는 워터마크를 해제하는 **방송 라이선스**(영구)를 구매하실 수 있습니다.
- 게임 참가자 중 **라이선스 등록자가 1명 이상**이면 그 인스턴스의 워터마크가 해제됩니다.
  합방이라면 한 분만 구매하시면 됩니다.

## 등록 방법

1. 구매 후 **VRChat 표시 이름(display name)** 을 제출해 주세요. (제출처: 구매 채널 안내 참조 — 추후 기입)
2. 등록 완료 후 반영까지 최대 10분 정도 걸립니다. **등록 후 10분 뒤에 인스턴스를 새로 만들어 주세요.**
3. 이미 인스턴스 안이라면 게임 내 **[라이선스 재확인]** 버튼으로 즉시 갱신할 수 있습니다.

## 유의사항

- 등록은 **VRChat 표시 이름 기준**입니다. 닉네임을 변경하시면 해제가 풀리므로,
  변경 후 재등록을 요청해 주세요 (무료).
- 라이선스는 **구매하신 방송인 본인이 참가하는 방송**에 한합니다. 타인 방송을 위한 대여는 허용되지 않습니다.
- 라이선스 범위: 공개 송출(플랫폼 무관). 사적 화면공유는 라이선스 없이 가능합니다.
